Changed since v2

On wide layouts the number pad's top edge lines up with the grid's top edge, in both hands and all themes (structural: shared grid row, no fixed offset). Nothing else changed.

Changed in v2 (since v1)

Statistics live only in the dialog (Option A and its toggle are gone). The menu button stays at the header's right end in left-hand mode too; only the columns swap. Reset puzzle… is disabled with no puzzle, like Share. The pad's six tools are two columns, "Input and help" (Pen/Pencil, Coach, Hint) and "Corrections" (Undo, Clear, Erase all pencil), set apart by a wider gutter and a hairline; the pad is a group, not a toolbar. A confirmed Reset and a New Puzzle load put focus on the grid. Generation is simulated. Labels, names and announcements now follow fspec-008 ("Theme changed to …").

What to try

  • Number pad. Compare the two columns across all five themes and with Narrow frame. Tab from digit 9: Pen/Pencil → Coach → Hint → Undo → Clear → Erase all pencil → Check. Arrow keys do nothing inside the pad.
  • Menu. Click ☰, or focus it and press Enter, Space, ↓ (first item) or ↑ (last). Inside: ↑/↓ wrap, Home/End, letter type-ahead, Enter/Space. Esc and Shift+Tab return to ☰; Tab goes on to Difficulty. Theme and Left-handed leave it open.
  • Reset puzzle… Cancel returns focus to ☰. Confirm clears entries, says "Puzzle reset." and focuses the grid; then ↓ or Home selects row 1, column 1.
  • New Puzzle. The board has progress, so it confirms first. Generation takes about a second; the grid takes focus when it loads. Choose Diabolical or Nightmare to see the slow path: Cancel appears after 1.5s and takes focus if it was still on New Puzzle; Cancel returns focus to New Puzzle. Move focus elsewhere (for example open the menu) while it generates and the load leaves it there.
  • Difficulty. A change generates too, but focus goes back to the selector.
  • Show win. Focus goes to New Puzzle (and an open menu closes). Share and Reset stay enabled. New Puzzle from there skips the confirmation and lands on the grid.
  • No puzzle. Share puzzle and Reset puzzle… go dimmed but stay focusable and do nothing. Starting a puzzle enables them, live if the menu is open.
  • Narrow frame. Left-handed leaves the menu (R6). With it focused, crossing the breakpoint moves focus to Mountain.
  • The Focus and Said readouts in this strip show the focused element and the last live-region announcement.

Not shown

Copy-failed Share (Link notice), the honest-fallback offer and failed requests. Digits, Hint, Clear, Undo and Check are visual only; Pen/Pencil and Coach toggle.
